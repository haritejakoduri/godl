What you can do with godl

godl downloads things from the terminal: plain links, videos from sites like YouTube, torrents, and files on a WebDAV server. Downloads run in the background, so they keep going after you close the terminal.

A file from a linkAny direct http(s) addressgodl url A video or its audioYouTube and other sitesgodl social Just watch itStream it, save nothinggodl play A torrentMagnet link or .torrent filegodl torrent Files on a serverYour NAS or cloud over WebDAVgodl webdav Share a folderTo other devices on your networkgodl serve

Start here

Run godl with nothing after it. That opens the dashboard: a full-screen list of your downloads with live progress. Press n to start a download, q to leave. Leaving does not stop anything.

godl

Everything the dashboard does also exists as a command, which is what the rest of this guide shows. Three things hold for every kind of download:

  • It runs in the background. The command returns at once and prints a job ID. Check on it with godl or godl list.
  • It lands in your Downloads folder unless you pass -o with another place.
  • It can be paused, resumed and retried by its job ID. See Manage downloads.

Stuck on a command? Add --help to it, for example godl torrent --help, for the full list of options.

Download a file from a link

For any direct http(s) address. A download that gets interrupted resumes where it stopped, and large files are fetched in several pieces at once when the server allows it.

godl url https://example.com/big-file.iso
godl url https://example.com/big-file.iso -o ~/isos/big.iso   # choose where it is saved
godl url https://example.com/big-file.iso -c 8                # 8 pieces at once (default 4)
godl url https://example.com/big-file.iso -R 2M               # cap the speed at 2 MiB/s

Check the file is intact

If the site publishes a SHA-256 checksum, pass it. godl compares it once the download finishes, and deletes the file and fails the job if it does not match.

godl url https://example.com/big-file.iso --sha256 <64-character-checksum>

Files behind a login

Send a token, a cookie, or the cookies exported from your browser. They are saved with the job, so resume and retry keep working.

godl url <link> -H "Authorization: Bearer abc"
godl url <link> --cookie "session=abc"
godl url <link> --cookies cookies.txt                         # a browser's cookies.txt export
godl url <link> --user-agent "Mozilla/5.0" --referer https://example.com/

Many links at once

Put one link per line in a text file. Each becomes its own download, and one bad link does not stop the others. With several links, -o is the folder they go into.

godl url -i links.txt -o ~/Downloads/batch

Save a video or its audio

For YouTube and the many other sites yt-dlp supports. godl fetches and maintains its own copy of yt-dlp and ffmpeg the first time they are needed. You install nothing.

godl social <link>                 # best quality
godl social <link> -p 1080p        # at most 1080p
godl social <link> -p 720p
godl social <link> -p audio        # audio only
godl social <link> -o ~/Videos

The quality names are best, 1080p, 720p, 480p, worst and audio. To see exactly what a link offers before downloading:

godl social <link> --list-formats

Private, members-only or age-restricted videos

These usually just need the cookies of a browser where you are logged in.

godl social <link> --cookies-from-browser firefox

A whole list

godl social -i links.txt -p 720p

Watch without saving

Streams the link straight into a player window. No download is created and nothing is written to disk. The quality names are the same as above.

godl play <link>
godl play <link> -p 720p
godl play <link> -p audio

This needs mpv or VLC installed. godl uses mpv when both are present. It does not install a player for you.

Torrents

Give it a magnet link or the path to a .torrent file. Quote magnet links, because they contain characters the shell would otherwise interpret.

godl torrent "magnet:?xt=urn:btih:..."
godl torrent ~/Downloads/ubuntu.torrent -o ~/isos

Take only some of the files

List what is inside first, then choose by number, by range, or by name pattern.

godl torrent <magnet> --list-files
godl torrent <magnet> --files 2,5-7
godl torrent <magnet> --files "*.mkv"

Watch while it downloads

godl fetches the part you are about to watch first, so playback starts within seconds. Use the job ID printed when the torrent started. This also needs mpv or VLC.

godl stream <job-id>
godl stream <job-id> --file 3      # a specific file, numbered as in --list-files

Keep sharing afterwards

By default a torrent stops uploading the moment it finishes. To seed, set a ratio, a time, or both; whichever is reached first ends it.

godl torrent <magnet> --seed-ratio 1.5
godl torrent <magnet> --seed-time 2h

Faster, through TorBox

With a TorBox account, TorBox can download the torrent on its servers first; godl then fetches the files from TorBox over a fast direct connection. That is usually much quicker when a torrent has few peers, and instant when TorBox already has it. Save your TorBox API key in Settings first. The dashboard and the web page then ask, for each torrent, whether to use TorBox or this computer.

godl torrent <magnet> --torbox
godl torrent <magnet> --p2p         # skip TorBox when it is the default
  • Keep a .torrent file where it is until the download finishes. godl reads it again when a job resumes.
  • A web address that points to a .torrent does not work directly. Save the file first, then pass its path.
  • A speed limit (-R) on one torrent applies to all running torrents together.

Files on your own server

For a NAS, Nextcloud, or any storage that speaks WebDAV. Save the server once under a short name. You are asked for the password, and it is stored readable only by your user account.

godl connection add mynas --url https://dav.example.com/files/alice/ --username alice
godl connection list
godl connection remove mynas

Then download a single file, or a whole folder with everything inside it:

godl webdav mynas /Photos/2024/beach.jpg
godl webdav mynas /Photos -o ~/Pictures     # the whole folder, structure kept

Browsing is easier in the dashboard: press w there to walk through the server's folders, tick what you want, and download it. See The dashboard.

Share a folder with other devices

The other direction: turn a folder on this machine into a small server, so a phone or another computer on your network can fetch files from it.

godl serve ~/Public --username alice         # asks for a password, then prints the addresses
godl serve ~/Public --host 127.0.0.1         # this machine only, no password needed
godl serve ~/Public --self-signed --username alice   # https

godl prints the addresses other devices can use. Each one offers two things:

  • A web page. Open the address in any browser, tick files or folders, and download them as one zip.
  • A network drive. The same address with /dav/ on the end can be mounted in Windows Explorer, macOS Finder or a Linux file manager.
  • It is read-only unless you add --allow-write.
  • It refuses to start on your network without a username and password, so nobody can browse the folder by accident.
  • It runs until you press Ctrl+C.

Manage downloads

Every download is a job with a short ID. godl list shows them all.

godl list                   # every job, its state and its ID
godl pause <job-id>
godl resume <job-id>        # continue from where it stopped
godl retry <job-id>         # start over from scratch
godl cancel <job-id>
godl remove <job-id>        # take it off the list, keep the file
godl remove <job-id> --purge   # take it off the list and delete the file

A job is always in one of these states. The dashboard uses the same colours:

  • queued
  • active
  • paused
  • seeding
  • completed
  • failed
  • canceled

On the first screen, a adds a server and d removes one. Inside a server:

Settings

Press s in the dashboard. Changes are saved as you make them.

SettingWhat it controls
Max concurrent downloadsHow many jobs run at once. The rest wait as queued and start on their own, oldest first. 0 means no limit.
Default rate limitThe speed cap for each new job that does not set its own with -R, such as 2M.
Global bandwidth limitA cap on link and WebDAV downloads combined. Torrents and videos are each held to it separately.
Auto-retry on failureRetries a failed job by itself after a growing wait, up to the number of attempts you set.
Notify on completionShows a desktop notification when a job finishes. Works on Linux and macOS.
TorBox API keyLets torrents go through TorBox. Copy it from torbox.app → Settings.
Use TorBox for new torrentsMakes TorBox the pre-picked choice when adding a torrent.
Keep torrents in TorBoxOff: godl deletes a torrent from your TorBox account once its files are downloaded. On: it stays there.

Use it from your browser

Everything the dashboard does also works in a web page, with a video player on top: watch finished downloads, torrents while they download, files on your server, or a YouTube link, and pick the audio language.

godl web                                # turn it on and open it
godl web --off                          # turn it off

It is off until you turn it on, and only this machine can use it. To open it on your phone or another computer at home, give it a username and password:

godl web --network --username alice     # asks for a password
godl web --local                        # back to this machine only
  • Then open http://<this computer's address>:8787 on the other device. godl web prints the addresses.
  • If a video won't play in the browser, the player gives you a link to open in VLC, and a download link.
  • Use network mode on your home network, not across the internet: it is plain http.

Stay up to date

One command checks for a newer godl, yt-dlp and ffmpeg and installs what it finds. Try it first when video downloads start failing: video sites change often, and an old yt-dlp is the usual cause.

godl update
How you installed godlWhat godl update does for godl itself
Fedora / RHEL package (.rpm)Downloads the new package and installs it. Asks for your sudo password.
Install script, on Linux or an Apple-silicon MacReplaces the program in place.
Debian / Ubuntu package (.deb)Leaves godl alone. Install the new .deb from the Releases page.
Windows installerTells you a new version exists. Run the new installer from the Releases page.

New versions are published at github.com/haritejakoduri/godl/releases.

Good to know

  • Speed limits are written as 500K or 2M, per second.
  • Job history and settings live in ~/.local/share/godl. Uninstalling godl leaves that folder alone.
  • Playing anything (godl play, godl stream, o) needs mpv or VLC already installed.
  • Closing the terminal never stops a download. Restarting the computer interrupts them; they pick up again the next time you run godl.
